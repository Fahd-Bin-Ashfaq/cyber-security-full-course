# 🔌 Ports & Protocols (Simple Explanation)


---

## 📦 What is a Protocol?

A **protocol** is a set of rules that decide **how data is sent or received** over a network.  
Think of it like a **language** that two computers use to understand each other.

### 🛠 Examples of Protocols:

| Protocol | Use                                |
|----------|-------------------------------------|
| HTTP     | For websites (browsing)             |
| HTTPS    | Secure websites                     |
| FTP      | File transfer                       |
| SMTP     | Sending emails                      |
| POP3     | Receiving emails                    |
| DNS      | Finding website IPs from names      |
| DHCP     | Gives IP addresses to devices       |

---

## 🚪 What is a Port?

A **port** is like a **door** in a device that allows data to enter or leave.  
Each service uses a specific **port number** to communicate.

### 📌 Real-Life Analogy:

- 📬 Your home = Computer  
- 📦 Courier = Data  
- 🚪 Different doors = Ports  
- 🛎️ Doorbell rings for specific service (like HTTP or FTP)

This helps devices know **which application/service the data is meant for**.

---

## 🔢 Common Port Numbers:

| Service        | Protocol | Port Number |
|----------------|----------|-------------|
| Web (HTTP)     | HTTP     | 80          |
| Secure Web     | HTTPS    | 443         |
| File Transfer  | FTP      | 21          |
| Email Sending  | SMTP     | 25          |
| Email Receiving| POP3     | 110         |
| DNS Lookup     | DNS      | 53          |
| Remote Login   | SSH      | 22          |

---

## 🧠 Summary:

- **Protocols** = Set of rules (like a shared language between devices).  
- **Ports** = Door numbers used to access services on a device.

> For example:  
When you open a website, your browser connects to port **80** (HTTP) or **443** (HTTPS) on the server, using the **HTTP protocol** to request the webpage.
