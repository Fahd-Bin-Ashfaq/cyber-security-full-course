# 🌐 IP Versions (IPv4 and IPv6)

## 📘 IPv4 (Internet Protocol Version 4)

- IPv4 is the **older version** of IP.
- It uses a **32-bit** address.
- Written in **dot (.) format**.
- Total addresses: **about 4.3 billion**

### 🔹 Example:
192.168.0.1


---

## 📘 IPv6 (Internet Protocol Version 6)

- IPv6 is the **newer version** of IP.
- It uses a **128-bit** address.
- Written in **colon (:) format** using hexadecimal numbers.
- Total addresses: **almost unlimited** (3.4×10³⁸)

### 🔹 Example:
2001:0db8:85a3:0000:0000:8a2e:0370:7334


---

| Feature         | IPv4             | IPv6                           |

## 🧠 Tip:
Use the command `ipconfig` (Windows) or `ip a` (Linux) to check your IP address.
