# 🌐 What is Subnetting?

**Subnetting** is the process of dividing a big network into smaller parts called **sub-networks** or **subnets**.

### ✅ Subnetting helps in:
- Better **network organization**
- Improved **security**
- Efficient **IP address usage**

---

# 🔧 Why Use Subnetting?

Imagine you’re managing a big office with **200 employees**.  
Instead of giving all 200 devices one large network, you divide them like this:

- 👨‍💼 **HR Department** → Subnet A  
- 👨‍💻 **IT Department** → Subnet B  
- 📦 **Warehouse** → Subnet C

Now each department has its own smaller network (subnet), which makes the system:
- Easier to **manage**
- Faster to **troubleshoot**
- More **secure**

---

# 🏡 Real-Life Example

Think of a **city**:

- 🏙️ **City** = Big Network  
- 🏘️ **Streets** = Subnets  
- 🏠 **Houses** = Devices (like laptops, printers, etc.)

Instead of putting all houses randomly in one place, we organize them into streets.  
**Subnetting works the same way in networks!** ✅
